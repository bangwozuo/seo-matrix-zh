## 能力描述

1. **S1 监测数据解析**：排名（「词」：第 X 位 vs 第 Y 位）、点击量（N 次 vs 基线 N 次）、索引状态三行类指标；阈值规则支持用户给定（自动抽取）或默认值
2. **S2 阈值判定**：排名下滑 ≥5 位 warning、≥10 位 critical；点击周环比 ≥15% warning、≥25% critical；已收录变未收录 critical；上升不告警仅记录
3. **S3 更新建议**：每条 critical 给排查方向（算法公告时间线 / 页面改动 / 收录丢失优先处理），未达阈值项如实记录不夸大

> 以下步骤的数值部分（阈值、频次、预算）由 `scripts/run_flow.py` 确定性计算，模型不得口算替代。

## 使用步骤

### 方式一：纯提示词编排

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供监测日期、基线日期、逐词排名对比与点击量数据
3. 按 S1→S2→S3 得到预警清单与更新建议

### 方式二：带脚本（端到端产物）

```bash
python scripts/run_flow.py --input examples/input.json --outdir out
python scripts/run_flow.py --demo
```

脚本承担解析与阈值判定；归因与处置决策由模型完成并经人工复核。

## 边界（不做的事）

- ❌ 不实时抓排名——输入来自站长平台或监测工具导出
- ❌ 不把 1~4 位抖动判成告警
- ❌ 不承诺「X 天恢复排名」
- ❌ 不建议快排、刷点击等违规操作
