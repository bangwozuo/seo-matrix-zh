## 能力描述

1. **S1 程序化页面生成**：解析模板（H1/meta 模板 + 段落结构）与数据集（条目N：字段=值），逐条渲染页面要素；meta ≤155 字符校验；缺字段条目进异常清单不编造
2. **S2 多语言写作校验**：目标语言与术语表解析（原词→译法→依据），逐条核对术语在页面要素中的出现次数与一致性，未出现者标 ⚠️ 人工确认
3. **S3 汇总落盘**：页面清单 + 术语表 + 异常项三件套

> 以下步骤的数值部分（阈值、频次、预算）由 `scripts/run_flow.py` 确定性计算，模型不得口算替代。

## 使用步骤

### 方式一：纯提示词编排

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供模板 + 数据集（步骤输入一）与目标语言 + 术语表（步骤输入二）
3. 按 S1→S2→S3 得到多语言页面产出包

### 方式二：带脚本（端到端产物）

```bash
python scripts/run_flow.py --input examples/input.json --outdir out
python scripts/run_flow.py --demo
```

脚本承担模板渲染与术语一致性核对；FAQ 文案与正文成稿由模型完成，
可衔接 multilingual-writing / programmatic-page-generate 技能的完整输出。

## 边界（不做的事）

- ❌ 不编造数据集缺失的字段——缺就进异常清单
- ❌ 不自行折算汇率与尺寸单位
- ❌ 不使用目标语极限词（best / No.1 / 100% 同样禁止）
- ❌ 不自动发布——只产出内容包，发布前须当地负责人人工复核
