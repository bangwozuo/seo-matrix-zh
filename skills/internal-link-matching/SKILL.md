# 内链智能配对

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_dev_03_sk06` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | SEO 架构师 |
| 能力族 | — |
| 复杂度 | `M` |
| 阶段 | `P2` |
| 复用度 | 低 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

页面间语义配对给出锚文本建议

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source_set` | string | ✅ | 需要被映射的条目 |
| `target_set` | string | ✅ | 映射的目标体系或清单 |

## 输出规格

映射与配对

- `mapping`：逐条给出对应关系
- `unmatched`：两侧无法对应的条目
- `suggestions`：对未匹配项的建议做法

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

### 方式三：带脚本（确定性计算，数值可复核）

```bash
python scripts/match_links.py --input examples/input.json --outdir out
python scripts/match_links.py --demo --outdir out      # 无输入也能看效果
```

脚本承担**确定性部分**（内链智能配对的解析、阈值/相似度判定、产物落盘），
模型承担语境解读与建议撰写。数值一律以脚本输出的 配对结果.csv / matching.json / 配对报告.md 为准；
缺依赖时脚本会提示并以非零退出码结束，不静默失败。

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）
